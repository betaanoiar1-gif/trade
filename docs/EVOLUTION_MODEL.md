# Evolution Model

Evolution is separated from execution and accounting.

## Genome
Logic tree, features, parameters, entry/exit rules, position sizing, risk and execution policy, canonical hash.

## Operators
Mutation, crossover, novelty archive, niching/speciation and diversity pressure.

## Objectives
Return, Sharpe, Sortino, drawdown, stability, OOS/WFA, turnover, fees, execution sensitivity, capacity, complexity, novelty and correlation. Profit alone is never the selection objective.

## Lifecycle
Population -> evaluate -> Pareto rank -> diversity/novelty pressure -> survivors/extinct -> reproduce -> checkpoint -> next generation.
